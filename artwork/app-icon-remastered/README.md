# App icon artwork

Generated with the built-in image generation tool. All three planet variants and ten ship variants are selectable in Menu > App icon; Classic retains the original primary icon.

Planet variants: Emerald (v2) preserves the original green planet with a broad luminous lime ring; Orbital (v3) adds a brushed titanium orbital ring and faceted terrain; Nebula (v4) uses jade atmospheric bands, slender gold-edged rings and a soft teal nebula background. All are opaque square illustrations with no text or pre-rounded corners.

Ship prompt: Keep the attached ship design, colors, proportions, right-facing top-down orientation and components. Place centered on opaque square very dark midnight-green space background, faint soft teal radial glow and a few tiny stars. Whole ship visible with safe margins. No planet, ring, text, added machinery, frame, rounded corners or drop shadow. Consistent dark teal-green starfield theme; do not redesign the ship.

Ship references: ios/Resources/ship-hd-0.png through ship-hd-9.png. In-game ship artwork is unchanged. Build-time sizing uses sips and preserves the generated compositions. ios/app-icons.json maps picker entries to these sources.
